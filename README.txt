# QYRENOVA Website

Static, Hostinger-compatible landing website for QYRENOVA.

## Files
- index.html — main page
- styles.css — responsive design
- script.js — mobile navigation

## Upload to Hostinger
1. Open hPanel.
2. Open Websites → Manage for the domain/subdomain where this site will live.
3. Open File Manager.
4. Upload the three files into the site's `public_html` directory (or the document root for `shop.qyrenova...`).
5. Make sure `index.html` is in the document root.
6. Replace placeholder email `hello@qyrenova.com` with the real contact email.

## Important
This is a static company website/landing page. It does not include a database, login, payments or an admin CMS. Those can be added later.

The current page uses an abstract CSS molecular visualization, so no external image license is required for the hero graphic.
